# Genomic Plotter

A modular Python toolkit for creating reproducible genomics and transcriptomics plots. Each plotting script accepts real tab-separated input data, validates it, and writes a publication-resolution PNG. Synthetic examples are available only when explicitly requested with `--demo`.

## Plot types

| Script | Purpose | Input format |
|---|---|---|
| `scripts/plot_metagene.py` | Mean signal across normalized gene-body bins | Numeric TSV matrix: rows are genes, columns are bins |
| `scripts/plot_metaorf.py` | Signal profiles across ORFs | TSV columns: `orf`, `position`, `signal` |
| `scripts/plot_circos_data.py` | Circular chromosome-level value plot | TSV columns: `chromosome`, `value` |
| `scripts/plot_mutation_impact.py` | Impact scores by protein domain | TSV columns: `domain`, `impact_score` |

**Scientific note:** these scripts visualize values supplied by the user. They do not calculate read coverage, call variants, infer ORFs, or perform statistical testing. A plot is only as meaningful as the input data and upstream analysis.

## Install

Python 3.10 or newer is recommended.

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
python -m pip install -r requirements.txt
```

## Run a plot with your data

### Metagene profile

Prepare a numeric TSV matrix with one gene per row and normalized bins across columns (no header row):

```bash
python scripts/plot_metagene.py --input data/gene_signal_matrix.tsv --out plots/metagene.png
```

### metaORF profile

Input example:

```tsv
orf	position	signal
ORF1	0	0.25
ORF1	1	0.31
ORF2	0	0.18
ORF2	1	0.27
```

```bash
python scripts/plot_metaorf.py --input data/orf_signal.tsv --out plots/metaorf.png
```

### Circular chromosome plot

Input example:

```tsv
chromosome	value
chr1	120
chr2	95
chr3	141
```

```bash
python scripts/plot_circos_data.py --input data/chromosome_values.tsv --out plots/circular_values.png
```

The current circular plot is a radial bar chart, not a full Circos ideogram with genomic coordinates, links, or tracks.

### Mutation impact by domain

Input example:

```tsv
domain	impact_score
N-term	12.5
DBD	81.2
Linker	35.0
CTD	64.1
```

```bash
python scripts/plot_mutation_impact.py --input data/domain_impact.tsv --out plots/mutation_impact.png
```

## Synthetic demo mode

Use `--demo` only to test plotting and installation. Demo data are generated by the script and are **not biological results**.

```bash
python scripts/plot_metagene.py --demo
python scripts/plot_metaorf.py --demo
python scripts/plot_circos_data.py --demo
python scripts/plot_mutation_impact.py --demo
```

Every script creates the output directory if needed, writes the PNG, and exits without opening a GUI window, making it suitable for servers and CI.

## Tests

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs the unit tests and smoke-tests all four demo commands.

## Limitations

- Metagene input must already be a numeric matrix of comparable normalized bins; gene orientation and normalization are upstream responsibilities.
- metaORF values are plotted as provided; the script does not identify ORFs or derive translation signal.
- The circular chart accepts one value per chromosome/category and does not draw genome-scale coordinates or structural-variant links.
- Mutation impact scores must be calculated upstream using a documented scoring method.
- No demo output should be reported as experimental evidence.
